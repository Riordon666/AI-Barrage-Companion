# AI Barrage Companion v0.1.0 预发行说明

## 概述

AI Barrage Companion（ABC）首个预发行版本。这是一个 Windows 桌面端的 AI 驱动虚拟弹幕陪伴应用——截取屏幕、分析活动、生成弹幕，在透明悬浮层中滚动显示，营造"被观看、被吐槽、被陪伴"的直播氛围。

**核心理念**：把 AI 从聊天框里的助手，变成屏幕上的虚拟观众。

---

## 系统架构

```
屏幕截图 ─→ 上下文提取 ─→ OCR 识别 ─→ 帧差分析 ─→ 隐私过滤
                                                    ↓
透明渲染 ←── 弹幕调度 ←── 发送缓冲 ←── AI / 模拟生成 ←── 弹幕缓存
```

- 截屏与 AI 生成完全解耦，互不阻塞
- 自适应弹性算法自动适应各类 API 延迟（<1s ~ 35s+）
- 三层降级保障：AI → 缓存 → 模拟弹幕

---

## 核心功能

### 屏幕感知

| 能力 | 说明 |
|------|------|
| 帧差分析 | 缩略图对比，识别 idle / normal / fast / stuck / highlight 五类场景 |
| 窗口检测 | 50+ 应用签名，覆盖游戏/编程/浏览器/媒体/聊天/办公/终端 |
| OCR 识别 | Windows 内置引擎，Tesseract 降级；累积模式收集完整上下文 |
| 隐私过滤 | 严格/均衡两档，所有屏幕内容上传功能默认关闭 |

### 弹幕生成

| 能力 | 说明 |
|------|------|
| AI 弹幕 | 10 家提供商，OpenAI + Anthropic 双协议 |
| 模拟弹幕 | 5 类人格 × 多场景模板，无 API Key 也能运行 |
| 自适应批次 | EMA 追踪 API 延迟，动态调 batch/concurrency/buffer 阈值 |
| 冷启动预热 | AI 就绪前持续注入模拟弹幕，体验不空档 |
| 成本混合 | 沉浸/均衡/节省三档，控制 AI 与模拟弹幕比例 |
| 弹幕缓存 | 按场景+屏幕上下文缓存，减少重复 API 调用 |

### 弹幕渲染

| 能力 | 说明 |
|------|------|
| 透明窗口 | PySide6 置顶无边框，点击穿透 |
| 多轨道 | 低 3 / 中 6 / 高 10 条同时显示 |
| 去重调度 | 文本去重 + 密度限制 + 优先级插队 |
| 视觉调节 | 字体大小 / 显示区域 / 不透明度 / 移动速度 |
| 速度统一 | 五档速度，人格倍率 0.85–1.05，抖动 ±5% |

### 控制面板

- 浅色紫黄配色，侧边栏导航
- 首页：问候卡片 + 实时统计（弹幕数、缓存池、API 延迟 EMA）
- 弹幕设置：密度 / 字体 / 区域 / 不透明度 / 速度滑块
- API 配置：提供商联动 / Key 管理 / 连接测试 / 历史配置
- 系统托盘：显示/隐藏面板、退出应用

## 已知局限

- 仅支持 Windows 主屏，多显示器适配未完成
- 不支持 DirectX 游戏画面截取（OBS 虚拟摄像头方案待调研）
- 无 TTS / 语音 / 长期记忆等重功能
- 未提供 PyInstaller 打包的独立 .exe
